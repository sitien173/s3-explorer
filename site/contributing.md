# Contributing

Contributions are welcome. Read the [contributing guide](https://github.com/sitien173/s3-explorer/blob/main/CONTRIBUTING.md) for setup, required checks, and commit style, then open a pull request.

Report bugs through [GitHub issues](https://github.com/sitien173/s3-explorer/issues). Report security problems privately as described in the [security policy](https://github.com/sitien173/s3-explorer/blob/main/SECURITY.md).

By contributing, you agree that your contributions are licensed under the [MIT License](https://github.com/sitien173/s3-explorer/blob/main/LICENSE).
