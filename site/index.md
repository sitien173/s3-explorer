# S3 Media Explorer

S3 Media Explorer is a Linux Electron desktop app for browsing, searching, managing, and streaming media objects in S3 and S3-compatible storage.

[Install & Run](install.html){: .btn .btn-primary } [View on GitHub](https://github.com/sitien173/s3-explorer){: .btn }

## Features

- Browse buckets in a virtualized list or grid view.
- Preview video, audio, images, PDF, and text with Quick Look.
- Stream large media through a signed loopback proxy, with seeking.
- Create, rename, move, download, and delete objects and folders.
- Create and delete buckets, and pin favorites in the sidebar.
- Connect with AWS profiles or any S3-compatible endpoint.
- Navigate fully by keyboard, with a command palette on `Ctrl + K`.
