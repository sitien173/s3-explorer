# S3 Media Explorer

[![CI](https://github.com/sitien173/s3-explorer/actions/workflows/ci.yml/badge.svg)](https://github.com/sitien173/s3-explorer/actions/workflows/ci.yml)

S3 Media Explorer is a Linux Electron desktop app for browsing, searching, managing, and streaming media objects in S3 and S3-compatible storage.

**Documentation:** https://sitien173.github.io/s3-explorer/

## Quick Start

Download the AppImage or Debian package from [Releases](https://github.com/sitien173/s3-explorer/releases), or run from source:

```bash
pnpm install
pnpm dev
```

Add an AWS profile or S3-compatible connection in the app.
